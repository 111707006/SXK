# T2 v3：量表详解

## 0. 一頁結論

使用者 2026-10-15：報告是賣點；先切成 0–3 再寫報告「太模糊」，家長填完量表要得到具體、站得住的結論與改善方向。

- **0–3 只留在內部**：九宮格的顏色、線上干預每月的名額照舊用它。**報告的結論改照每份量表自己的分法寫**。
- 每份做完的量表一段「量表详解」：總覽（各種作答各幾題＋一段結論）→ 每個面向一條（白話狀態、題數）→ 最需要練的一到兩個面向展開（在看什麼、哪幾題會／不穩／還不會、下一步先練哪一題、在家怎麼練、對應的線上干預）→ 三個月後對照。
- **三種講法**（使用者 10-15 選定）：① 量表自己的分級換成白話；② 講題數，不講百分比；③ 講孩子會什麼、下一步是什麼。
  **不用常模、不講「相当于几岁」、不講題目的起始月齡**（客戶 IT 說明書第七章禁止；第四種講法要先問客戶，見 §7 S-1）。
- 說明與練法的依據是**客戶網頁裡治療師寫的面向說明**（`what`、`tips`、`LEVELS`），由腳本抽、照用字表逐句改寫；不是模型自己發揮。
- 範例（粗大動作）證明了這一段的價值：48 個月、76 題會 69 題（91%）整支是「發展中符合預期」，但「平衡與球類協調」只會 4/8。只看整支分數會漏掉。

## 2. 資料

全部已經在手上，不必向家長多問：

- **快照的 `toolResults`**（`ToolResultV3`）：每支的 `answers`（逐題）、`score`（各面向數值與頁面分段、整支分段）、`context`（月齡、年級……）。
- **題庫**（`src/t2/kitv3/<code>.ts`）：面向、題目原文、選項文字、每題起始月齡（只用來挑題，不顯示）。
- **客戶說明**（新抽，§3）：每個面向的 `what`（在看什麼、為什麼重要）、`tips`（在家怎麼練）；整支的 `LEVELS[].head/txt`（各分級的建議）。
  24 支裡 19 支有面向的 what／tips；LQ、M-CHAT、ASQ3、QOL、EMO、TIC、氣質各自的欄位不同（見 §4）。

## 3. 客戶說明的抽取與改寫

- **抽**：`scripts/t2-extract-kitv3.ts` 的配方多抽一欄 `texts`：`facets: {key → {what, tips[]}}`、`levels: [{head, txt}]`（只抽原文，不改）。
  照舊不執行 HTML；`--check` 與結構測試照舊比對。
- **改寫表**（手寫）：`src/t2/kitv3/textAdapt.ts`，**客戶原句 → 改寫句**，以句為單位（以「。！？」切）。
  - 849 句裡 170 句踩用字表（最多：困难 46、落后 37、治疗 23、症状 20、偏低 17、尽快 17、转介 12）。D3／D4 放行後再算一次。
  - 改寫原則：只換掉禁字那幾個字詞，**意思、建議、轉介對象都不變**；「障碍」當「障礙物」講的改成別的詞（例：当小关卡），不整句丟掉。
  - 每一句要嘛有改寫、要嘛明列「不用」並寫理由（例：講治療師當面才做得到的觀察）。
- **護欄**（`test/t2ScaleDetailTexts.test.ts`）：① 抽到的每一句踩禁字的，改寫表都有一筆；② 每一句改寫過用字掃描；③ 改寫表裡沒有找不到原句的孤兒（客戶換版會紅）。
- 用字表放行：`src/utils/parentWording.ts` 的 `ALLOWED_PHRASES` 加 D3／D4 的詞（註明使用者 2026-10-15）。

## 4. 各族的講法

共同形狀（`src/t2/scaleDetail.ts`，純函式 `scaleDetailOf(result, bank) → ScaleDetail`）：

```
ScaleDetail {
  code, displayName, oneLiner,             // 量表名（D5）、這份在看什麼（一句）
  answerKinds: [{label, count}],           // 各種作答各幾題（照這支的選項，§4 各族）
  overall: string,                         // 總覽那一段（§5）
  facets: [{key, name, plain, asked, counts, graded}],   // graded=false：題數太少不單獨判
  focus: [{key, name, plain, what, items: {kind→[題目原文]}, next?: 題目原文, tips[]}],  // 最多 2 個
  flags: string[],                         // 轉介句等（沿用 score.flags）
}
```

| 族 | 量表 | 作答怎麼講 | 面向狀態 | 「下一步」 |
|---|---|---|---|---|
| 達成率 | GM、SOC、ADP、PLC、LANG、VOC（A 段）、ASQ3（五個領域） | 已经会／偶尔会／还不会 | 四段：已经稳定／大部分会了，还有几项不稳／还在发展中／需要优先关注 | 這一面還沒穩定的題裡起始月齡最早的一題 |
| 頻率 | ASB、ASR、AB、ATT、SP、SPb、SNAP-IV、CHEXI、LDP、LDS、EMO（症狀） | 照選項原文（很少或没有／偶尔／经常／总是……），只分「常出现」（最差兩檔）與其他 | 三段或四段照頁面：没有需要留意的／有几项需要留意／常出现、需要优先关注 | 不講「先練」，改「先从这几种情形着手」：最常出現的兩三題 |
| 七級 | ADL | 自己做到（最好兩檔）／需要一点帮忙（中間三檔）／大人做为主（最差兩檔） | 頁面三段 | 「需要一点帮忙」裡起始月齡最早的一題 |
| 帶差 | LQ | 照頁面的帶：每一帶穩定做到幾題 | 帶差 0／1／2／≥3 的白話 | 還沒穩定的最低那一帶的題 |
| 風險題 | M-CHAT（第一階段） | 列出答到「要多留意」那一邊的題 | 頁面三段 | 不講；接預約 |
| 嚴重度 | TIC | 動作型、聲音型各自的頻率與影響 | 頁面四段 | 不講；紅旗沿用轉介句 |
| 只描述 | QOL、氣質 | QOL 五個生活面向的白話；氣質九向度的偏向（沿用既有段落，補客戶 DIM_DESC／TIPS） | 不分級 | 不講 |

- 面向題數少於該支 `minItems`：只列題數，狀態寫「题数太少，这次不单独判断」。
- 選最需要練的面向：頁面分段最差的先，同段時達成率低（或常出現比例高）的先，最多 2 個；全部都是最好那段時不展開，總覽說明「各方面都稳定」。
- 題目原文照題庫，**不改寫**（客戶的題目，不在用字掃描範圍；畫面只引用）。

## 5. 總覽那一段（規則句，不經模型）

1. 有需要練的面向時，**不用**客戶整支分段的那段話（它會被早就會的題撐高，範例的 91%）；改講：「这次 N 题里已经会 X 题……不过「面向」还在发展中，是这次最需要练的地方」。
2. 沒有需要練的面向：用客戶整支分段的 `txt`（改寫後）。
3. 整支分段是最差那段、或 `score.flags` 有轉介：照客戶那一段的建議（改寫後，含「物理治疗评估」這類轉介）。

## 6. 快照、畫面、對照、活動

- **快照**：`T2_SCALE_DETAIL` 開著時，`POST /api/t2/findings` 生成 `T2FindingsV3` 時多存 `scaleDetails: ScaleDetail[]`（每支一份，依交卷順序）與 `detailVersion: 1`。報告頁看快照有沒有這一欄決定畫不畫，**不看開關**。
- **畫面**：`T2ReportV3` 在「各方面」之後、「作答回顾」之前加「量表详解」；每支一張卡（範例的版面）；列印照出；375 寬可讀。
- **三個月後對照**：生成快照時，同一支若有更早一筆完整作答（不限 90 天），存 `previous: {computedAt, facets: [{key, counts}]}`；畫面在面向那一條旁寫「上次 4/8 → 这次 6/8」。沒有就不出。
- **對應的線上干預**：第一版只放「去线上干预看『动作发展』这一项的活动」連結（那一頁已照月齡與顏色排好）；**面向 → 活動**的對照要內容團隊標（S-4），之後另開票。
- **模型段落**（`proseV3` 的各方面段落）：這一版不動；之後另開票讓它讀 `scaleDetails` 的事實（驗證器要擋與事實不符的面向、題目、數字）。
