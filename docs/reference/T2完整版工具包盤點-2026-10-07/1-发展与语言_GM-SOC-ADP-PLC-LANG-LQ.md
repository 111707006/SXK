# 完整版工具包（2026-09-23）第一组调查：GM / SOC / ADP / PLC / LANG / LQ

调查方式：只读文字，未执行任何 HTML／JS。新档目录 `kitfull/森心康评估工具包_完整版/网页版/`；旧版 `src/t2/toolkit/sxk-*.ts`。
题数、逐月龄题数、旧新逐题比对，都是我另写 Python 脚本用正则从原文抽出来算的（脚本在同目录 `cmp.py`、`cmp2.py`、`cnt.py`），没有执行页面里的任何程式。

## 0. 先看这一段（跨工具的结论）

1. **GM / SOC / ADP / PLC 四支是同一个模板**（同一份 JS，只有资料段与报告文案不同）。我把四份 `var S={ans` 之后的程式逐行 diff，计分、分段、postMessage、必填检查、年龄处理的程式码**完全一样**，差异只在报告里的文字。所以下面这四支的「计分／分级」写一次、四支共用。
2. **LANG** 同样的计分公式，但是单一填表人、没有两份问卷、分段切点不一样（最低一档 50 而非 55）。
3. **LQ** 是完全不同的设计：56 题全部同方向、选项 3/2/1/不确定、不确定不计分母、主要结论是「带差」（最高稳定达成带 vs 实足年龄所在带），不是百分比。
4. **旧题沿用情形**：ADP 34/40 逐字相同（月龄也全同）；LANG 40/60 逐字相同（月龄全同）；GM 16/40；SOC 1/40。**四支旧工具都不是「同一份题库」**，新版全部扩大（GM/SOC/ADP 各 84 题、LANG 132 题），ADP 与 LANG 是旧题的超集加新题，GM、SOC 是改写重编（概念相近、字面不同，分面向也重新切）。**旧 `sectionKey` 会撞名但意义不同**（例：ADP 旧 A5＝生活应用，新 A5＝记忆与学习；GM 旧 P1–P5，新 G1–G7；SOC 旧 S1–S5，新 S1–S7 且 S3 意义变了）。
5. **分级栏位**：每支新档只有**一套**分级（同一个 `LEVELS`／`PCTB`／`RULES` 同时画在报告上、也送进 postMessage），不像旧档三套。postMessage 载荷是 `{sxkTool:1,id,name,grade,score,note}`：`grade`＝分级的**中文名称字串**，`score`＝整数百分比（0–100），`note`＝人读的字串。
6. **分级最自然对应 0–3**：GM/SOC/ADP/PLC/LANG 是四档 `LEVELS`，由好到坏索引 0、1、2、3 直接对应。LQ 以「最大带差」0/1/≥2（或 ≥3）对应，红旗会覆盖。
7. **要紧的设计风险（见各节）**：GM 一类的模板是「累积题」（月龄 ≥ 题目月龄的**所有**题都计分，包含很早就该会的），百分比对大月龄孩子**很钝**：GM 48 个月孩子功能落后整整 12 个月，仍得 89%（「发展中符合预期」）。LQ 的百分比有结构性下限 33%（「还不行」＝1 分）。LQ 的带差对**单一题**极度敏感（一题「偶尔可以」就会卡住整个带）。

## 1. SXK-GM　粗大动作发展量表

**文件**：`森心康_粗大动作发展量表_完整版_SXK-GM.html`

### 1. 标题与年龄
- h1：`森心康粗大动作发展量表 · 完整版`，small：`SXK-GM 完整版 ｜ 0–7 岁 ｜ 七面向 84 题 ｜ 家长报告＋治疗师／教师观察`。资料档标记 `SXK-GM-F`，存档 `ver:1`，没有其他版本字串。
- 页面自己执行的月龄范围：**0–84 个月，只是软提示，不挡**。`refreshAge()`：`if(m>84){... "本表适用 0–84 个月（0–7 岁），此年龄已超出范围，结果仅供参考。"}`；没有下限检查。月龄由出生日期与施测日期算（`calcAge()`，未满两岁且填早产周数时 `m=m-Math.round(pre/4.345)` 做矫正）；也可手动改 `f_age`，`start()` 里 `S.age=isNaN(m)?calcAge():m`。
- `start()` 必填：儿童姓名、正确的出生／施测日期、**评估人员**（`f_staff`，页面写「治疗师／评估人员姓名」）。排除性因素未填会 `confirm()` 但可以继续。

### 2. 填表人表单
`FORMS`：`p` 家长报告版、`t` 治疗师／教师观察版。**两份题目逐字相同，只有说明文字 `d` 不同**（家长＝「依平常在家中、公园与日常活动中的表现」；治疗师＝「实际动作观察中直接判定」）。至少填一份即可产生报告；两份都填会取平均并列出差异。**在家的家长用 `p`。**

### 3. 题目结构（7 面向，每面向 12 题，共 84）
| key | 名称 | 题数 | 题目月龄范围 |
|---|---|---|---|
| G1 | 俯卧与头颈控制 | 12 | 0–10 |
| G2 | 翻身与姿势转换 | 12 | 1–24 |
| G3 | 坐姿与躯干控制 | 12 | 3–54 |
| G4 | 爬行与移位 | 12 | 6–42 |
| G5 | 站立与行走 | 12 | 4–48 |
| G6 | 跑跳与下肢力量 | 12 | 20–66 |
| G7 | 平衡与球类协调 | 12 | 15–72 |

- 选题方式（`buildItems`）：每题带 `m`（「约 N 个月」）。**`ok = age >= it.m`**——月龄 ≥ 题目月龄的题**全部**计分，没有 basal／ceiling、没有起始点、没有上限（没有「过了几个月就不出」）。未到年龄的题不出；勾「显示全部题目」会出，标「参考·不计分」，不并入达成率。
- 家长实际答题数（我数的）：**12 个月 39 题；36 个月 68 题；60 个月 81 题**（6 月 17、24 月 57、48 月 76、72 月以上 84）。分面向：12 月 `[12,8,8,7,4,0,0]`；36 月 `[12,12,10,11,11,7,5]`；60 月 `[12,12,12,12,12,11,10]`。
- 某面向当月龄 0 题时，页面显示「本月龄暂无适用题目」；`MIN_ITEMS=3`：适用题数 < 3 的面向不单独计达成率（`scored:false`，报告「题数不足」），但这些题照样进总达成率。

### 4. 作答选项
`OPTS`：`{v:2,"已经会"（稳定做得到）}`、`{v:1,"偶尔会"（有时可以、还不稳定）}`、`{v:0,"还不会"（尚未出现）}`。所有面向、两份表单相同。**没有「不适用／没观察到／跳过」**；`finish()` 要求每份已开始的表单**所有计分题都答**，否则弹窗并标红（`alert(f.n+"还有 N 题未作答…")`）。

### 5. 非题目输入
- **EXCL（排除性因素，7 项，下拉单选，必填但可 `confirm` 略过）**：`tone` 肌张力与关节活动度、`pain` 疼痛外伤手术、`asym` 左右对称性、`vision` 视力、`fit` 体重与体能、`exp` 活动空间与练习机会、`state` 施测配合度与当日状态。每项有 `bad:[...]` 清单。**不影响分数、不影响等级**；只在报告上出现「本次结果不能用来推论动作学习能力」警语与各项 `note`。家长可答大部分，但「肌张力与关节活动度」「左右对称性」实际要专业人员判断（选项是「未见异常／张力偏高（僵硬）／张力偏低（软）／关节活动受限／尚在评估中」）。
- **FLAGS（红旗，9 项，勾选）**：`reg` 动作倒退、`asym` 明显左右不对称、`tip` 踮脚走、`fall` 常无故跌倒、`stiff` 肢体特别僵硬或软、`walk` 满 18 月仍不会独走、`tired` 活动一下就喊累／腿痛、`seiz` 抽搐癫痫脑部疾病缺氧史、`pre` 早产低体重新生儿加护。**不影响百分比与等级**；勾了就在报告顶端出「需要优先处理的情形」，并在「接下来建议」加转介句（`if(S.flags.reg)`…）。
- **CTX（背景，7 项，下拉）**：早产、目前就学、目前接受的疗育、每天户外／大动作活动、家中活动空间、每天屏幕时间、已有诊断。只用在报告文字（屏幕时间＋户外时间偏少会出一句提醒）。
- 其他：转介来源、评估目的（下拉，非必填）、背景补充、临床备注、早产周数。

### 6. 计分（公式）
```js
function domStat(fk,key){
 var its=ITEMS.filter(x=>x.sec===key&&x.scored), A=S.ans[fk];
 var got=its.reduce((a,x)=>a+(A[x.no]||0),0), max=its.length*2;
 return {n:its.length,got,max,pct:max?Math.round(got/max*100):null,
         scored:its.length>=MIN_ITEMS, unstable:its.filter(x=>(A[x.no]===undefined?0:A[x.no])<2)};
}
function totPct(fk){ ... got/(its.length*2) ... Math.round(got/max*100) }   // 所有适龄题合并，不是各面向平均
function combinedDom(key){ 取已开始的各份表单的 domStat.pct，Math.round(算术平均) }
function combinedTot(){ 取已开始的各份表单的 totPct，Math.round(算术平均) }
```
- 面向％＝实得 ÷（适龄题数×2），四舍五入整数。总％＝**全部适龄题**得分合计 ÷（题数×2）（所以面向题数多的权重大；不是面向％的平均）。两份表单都填时，各份各算后再取平均。
- 另有描述性「月龄参考带」`BANDS`（0–12／13–24／25–36／37–48／49–60／61+）：`bandStat` 算每带「所有填表人都答已经会」的题数比例；`topBand()`＝最后一个 `n>=2 && pct>=80` 的带。**不是智龄**，不进 postMessage。
- 家长 vs 治疗师差距：面向差 ≥ 20 个百分点会出提示，不影响等级。

### 7. 分级
(a) 报告上的 `LEVELS`（好→坏，以**总达成率**与**各面向达成率**都用同一套 `band(p)`）：
| 序 | min | key（名称） | head |
|---|---|---|---|
| 0 | ≥85 | 发展中符合预期 | 各面向的达成率良好 |
| 1 | ≥70 | 部分项目待加强 | 多数项目已达成，部分尚未稳定 |
| 2 | ≥55 | 建议安排物理治疗评估 | 达成率偏低，建议安排评估 |
| 3 | 0–54 | 建议尽快安排完整评估 | 达成率明显偏低，建议尽快转介 |

（SOC/ADP 第 3 档名称是「建议安排发展评估」；PLC 是「建议安排语言评估」；切点同为 85/70/55。）

(b) postMessage（`render()` 末尾，原文）：
```js
try{window.parent.postMessage({sxkTool:1,id:"gm",name:val("f_name"),grade:bd.key,score:tot,note:"SXK-GM 完整版 总达成率 "+tot+"%"},"*")}catch(e){}
```
`grade`＝上表 key 字串（4 种之一）、`score`＝总达成率整数 0–100（`tot`＝`combinedTot()`，两份表单都填时是两份总％的平均）、`note` 固定句型。`id` 值：gm。**面向级的分数／等级不在 payload 内**，只在页内报告与「保存记录（JSON）」`collect()` 里（`doms:{G1..G7:pct}`，`tot`）。HUB（`SXK-HUB.html`）收到后只原样显示 `grade` 字串。

(c) 其他：「月龄参考带」（最高稳定达成带）、排除性因素警语、红旗警示——都是描述，不是等级。

**对 0–3 的映射**：`LEVELS` 索引 0/1/2/3 ＝ 0/1/2/3，直接对应；主维度＝动作（总达成率），也可取各面向 `pct` 再各自过 `band()`。红旗另当旁路（页面自己也说红旗「与达成率高低无关」）。

### 8. 家长在家做不到／需要注意
- 题目全是「平常表现」，没有器材或限时测验；但 `能单脚站五秒以上`、`能连续跑动五分钟以上`、`能骑两轮脚踏车` 需要家长实际看过。
- 「评估人员」必填栏（页面说是治疗师姓名）与排除性因素里的肌张力／对称性，需专业人员；在家场景要决定怎么填（见第 10 点）。
- 同一模板的「治疗师／教师观察版」不需要用。

### 9. 与旧版 `sxk-gm.ts` 比较
- 旧：5 面向 P1–P5（卧位与翻身／坐姿控制／爬行与站立／走跑跳／平衡与协调）×8＝40 题。新：7 面向 G1–G7×12＝84 题。**面向重新切分，key 与名称都不同。**
- 旧 40 题逐字出现在新 84 题的只有 **16** 题（42%）；有 14 题连 `startMonth` 也相同，2 题月龄不同（`能长时间坐着玩不需支撑` 10→12、`能双脚同时离地跳` 24→27）。其余 24 题是改写（例：`能手膝并用爬行`→`能手膝并用往前爬`，`能跑起来`→`能跑起来（双脚有腾空期）`）。
- 选项：旧 2/1/0（已经会／偶尔会／还不会）＝新，一字不差。`minItems:3` 同。
- 旧分段 tiers：`未见明显问题 85／轻微落后 70–84／中度落后 55–69／明显落后 0–54`；新为上表四个名称，**切点相同（85/70/55）、名称全不同**。
- 结论：**「改写重编的新题库」**（概念同、题目与面向不同）。旧 `P1–P5` 得分不能直接沿用到新题。

### 10. 开放问题
1. **累积题造成的钝感**（最重要）：我模拟「孩子在 age 月龄、功能停在 age−12 个月（早于 age−12 的题全 2 分，之后的题全 0 分）」，得分：12 月 3%、24 月 68%、36 月 84%、48 月 89%、60 月 94%（≥85 即「发展中符合预期」，所以 48 月以上落后一年也被判符合预期；24 月落后一年才会掉到「待加强」以下）。也就是说 **48 个月以上孩子整整落后一年仍落在「发展中符合预期」（≥85）**；落后半年更是 95–98%。固定切点 85/70/55 对大月龄几乎不敏感，对小月龄过度敏感。（SOC/ADP/PLC 同样：SOC 48 月落后一年 81%、ADP 48 月 71%、PLC 48 月 93%。）引擎要不要改成只看「接近月龄的题」或依月龄调切点？这是产品决策。
2. 「评估人员」必填，家长自填时填什么？
3. 排除性因素里需要专业判断的项（肌张力、对称性）家长无法回答，「尚在评估中」能否当缺省？
4. 没有「N/A」：家长不确定的题只能选一个答案，等于被当成 0/1/2 之一计分。
5. 总达成率里小面向（< 3 题）仍计入，但该面向不显示；例如 12 个月 G6/G7 为 0 题。
6. 早产矯正只对 <24 个月、`pre>0` 起作用；以 4.345 周／月四舍五入。

### 10. 开放问题
1. 年龄没有上下限；12 岁以后仍可填。
2. 题量随月龄线性累积，60 月 92 题、84 月 111 题；是否对家长限制只答最近的几个题？
3. 总达成率里包含年龄较小就应通过的大量旧题，同 GM 的钝感问题：48 月落后一年仍 76%（待加强），60 月落后一年 85%（预期内）。

## 6. SXK-LQ　儿童语言发展家长问卷（新工具，真正的「家长问卷」）

**文件**：`森心康_儿童语言发展家长问卷_完整版_SXK-LQ.html`。**不同于以上所有**：设计为家长自填，筛查用途，56 题全同方向。

### 1. 标题与年龄
h1：`森心康儿童语言发展家长问卷 · 完整版`；small：`SXK-LQ 完整版 ｜ 四个面向各 14 题，共 56 题 ｜ 七个月龄参考带 ｜ 口腔进食独立计分，不并入语言`。存档 `tool:"SXK-LQ-F",ver:1`。适用 **12–72 个月**（`1 岁 0 个月 – 6 岁 0 个月`），**只是软提示**（`refreshAge()`）：`ageBand(mo)` 低于 12 回 0 → 警示建议改用 SXK-PLC；高于 72 回 8 → 警示「已超出适用范围」并建议 SXK-NAR／SXK-SEN。不挡，仍可继续。**无早产矫正栏位。**年龄＝`y*12+m` 整月数（`calcAge()`）。
必填（`start()`）：孩子姓名、出生／填写日期、填表人姓名。排除性因素没填会 `confirm`，可继续。

### 2. 填表人
单一：「主要照顾者」（`f_staff`＝填表人姓名，`f_rel`＝与孩子的关系）。**没有治疗师版**。报告尾端有一栏「专业人员备注」（`f_pro`）是选填。**在家的家长就是预期使用者。**

### 3. 题目结构（4 面向×7 带×2 题＝56；加口腔 6 题独立）
- 面向 `DIMS`：`L1` 语言理解、`L2` 口语表达、`L3` 语音清晰度与可懂度、`L4` 沟通意愿与语用；各 **14 题 ＝ 7 带 × 2 题**。
- 月龄参考带 `BANDS`：B1 12–18、B2 19–24、B3 25–30、B4 31–36、B5 37–48、B6 49–60、B7 61–72（宽度 6,6,6,6,12,12,12）。
- **选题方式：不依月龄筛题**。56 题**一律全部出现**，不论孩子几岁（页面说「比您的孩子年龄带更高的题目，填『还不行』是正常的」）。所以家长答 **12 月 56 题、36 月 56 题、60 月 56 题**，另有口腔 6 题（独立、非必填）。
- 每题有提示 `o`（怎么观察的小说明），部分要求家长试做（例：`你说「把球给我」…不可以用手指`、`每次换位置再试一次`、`你说身体部位的名字，他能指出三个以上`、`问他叫什么名字`）。每题可选填「想到的例子」文字。
- 口腔进食与吞咽 `ORAL`（6 题，第二步骤）：`o1` 吃喝会呛咳、`o2` 一餐超过三十分钟、`o3` 拒绝咀嚼硬食、`o4` 容易作呕或吐、`o5` 含在嘴里不吞、`o6` 喝水汤从嘴角漏。**方向相反**（有问题＝高），**完全不进语言分数**。

### 4. 选项
- 主 56 题 `RESP`：`{v:3,"已经可以"（经常这样，已经稳定）}`、`{v:2,"偶尔可以"}`、`{v:1,"还不行"（目前还没看到）}`、`{v:-1,"不确定"（没观察过或不敢确定）}`。`MAXV=3`。**注意值是 3/2/1，不是 2/1/0**，「还不行」＝1 分，不是 0 分。**「不确定」不计入分母、也不当作 0 分**（见计分）。
- 口腔 `OFREQ`：0 没有／1 偶尔／2 经常／-1 不确定。

### 5. 非题目输入
- **EXCL（「需要先厘清的因素」，7 项，下拉，必填但可 confirm 略过）**：`hearing` 听力检查（`曾检查·通过／曾检查·有异常／从未检查／不确定`）、`ear` 中耳炎与耳鼻喉病史、`lang` 家中使用的语言、`dev` 整体发展与已知诊断、`input` 家中的语言输入、`know` 填表人对孩子的了解程度、`change` 近期重大变动。**不影响分数、不影响带差、不影响「建议」档**；只在报告出警语与「建议怎么做」里的条目（例如听力不是「曾检查·通过」就加一条「优先安排听力检查」）。家长可全部自答。
- **FLAGS（8 项，勾选）**：`noword` 两岁后几乎没口语、`regress` 语言退化、`noname` 叫名字常没反应、`nogesture` 几乎不用手势眼神表情弥补、`echo` 大量重复电视广告、`choke` 吃喝常呛咳、`frust` 因说不出而常哭闹生气动手、`teacher` 已上学且老师反映听不懂指令。**会覆盖结论**：`verdict()` 第一行 `if(FLAGS.some(f=>S.flags[f.k]))return ruleOf("flag")`。
- **CTX 5 项**：填表人（妈妈/爸爸/祖父母/其他）、就学、屏幕时间、家中排行、曾接受语言评估或疗育（只进报告背景；屏幕≥两到三小时出提醒）。
- 「想到的例子」每题选填文字、补充说明 `f_note1/2`、背景补充。

### 6. 计分（原文）
```js
var MAXV=3;
function domStat(d){ var sum=0,tested=0,na=0,done=0,fails=[];
 itemsOf(d).forEach(function(x){ var r=S.sc[x.k]; if(!r||r.v===undefined)return; done++;
  if(r.v===-1){na++;return}            // 不确定：不进分母、不加分
  tested++; sum+=r.v; if(r.v<MAXV)fails.push(...) });
 return {..., pct: tested>0 ? Math.round(sum/(tested*MAXV)*100) : null}; }
function overallPct(){ // 56 题合并，同样排除 -1 与未填
 ... tested++; sum+=r.v; ... return tested>0?Math.round(sum/(tested*MAXV)*100):null }
/* 最高稳定达成带：从 B1 起，该带以下每一题都要是「已经可以」 */

```
重点（实务上）：
- 百分比 `pct＝sum/(tested*3)`；「还不行」＝1 分，所以**百分比的结构下限是 33%**（全部「还不行」）。
- **最高稳定达成带要求「该带及以下每一题都是已经可以」**（`r.v!==MAXV` 就算 `bad`；`不确定` 或未填算 `na`，两者都使整条链在该带中断）。含意：只要 B1 有一题是「偶尔可以」，该面向 `lv=0`（「未达 B1」）；于是 36 个月（B4）的孩子带差＝4。若在较低带有任一「不确定」，`lv` 停在上一带且标「blocked」。
- 年龄在 12 月以下或 72 月以上，`gapOf` 为 null，`verdict()` 为 null（报告显示「尚无法给出建议」）。
- `finish()` 允许部分填答（只要 ≥1 题），未填的题不计分母，但会让最高稳定达成带判不出来。
- 面向 `fails` 是「得分 <3」的题（偶尔可以＋还不行），列在报告的待加强清单。

### 7. 分级
LQ 有**三层**，都在同一份页面里：
- (a) **带差 `RULES`（报告顶部大卡片＝主结论）**，由好到坏：
  | 序 | k | n（名称） | 条件 |
  |---|---|---|---|
  | 0 | g0 | 四个面向都与年龄带相当或超前 | `maxGap()===0` |
  | 1 | g1 | 有面向落后一个带 | `maxGap()===1` |
  | 2 | g2 | 有面向落后两个带以上 | `maxGap()>=2` |
  | — | flag | 有需要特别注意的情形 | **任一红旗勾选，凌驾**（「直接安排专业人员当面评估」；语言退化与呛咳先就医） |
  `GAPTXT[g]`：0 相当或超前；1 落后一个带（先在生活加强、三个月后再填）；2 落后两个带（建议 SLP 当面评估）；3 落后三个带（建议 SLP 当面评估＋听力检查）；4–7 落后四到七个带（尽快评估）。
- (b) **整体百分比 `PCTB`**（「整体：…」）：≥85 多数项目已稳定达成／≥65 大致跟得上，部分项目仍不稳定／≥45 有相当比例的项目尚未达成／<45 多数项目尚未达成。切点 85/65/45。表格里每带×面向的色块也用 85/65/45。
- (c) 每面向的「最高稳定达成带（B1–B7 或未达 B1）」与带差。
- (d) postMessage（原文）：
```js
window.parent.postMessage({sxkTool:1,id:"lq",name:val("f_name"),grade:(v?v.n:"—"),
  score:(op==null?0:op),
  note:"SXK-LQ 完整版 最大带差 "+(maxGap()==null?"—":maxGap())+"　理解 "+(a.L1.pct==null?"—":a.L1.pct+"%")+"／表达 "+(a.L2.pct==null?"—":a.L2.pct+"%")+"／清晰度 "+(a.L3.pct==null?"—":a.L3.pct+"%")+"／语用 "+(a.L4.pct==null?"—":a.L4.pct+"%")},"*")
```
  `grade`＝(a) 的名称字串（5 种可能：四个 `RULES.n` ＋「—」）；`score`＝整体百分比（可能 null→0）；`note` 里嵌最大带差和四面向百分比。**带差本身和各面向 `lv` 不在 payload 的结构栏位里，只在 note 的文字与存档 `collect()`（`pct`、`lv`、`gap`、`overall`）。**

**0–3 映射建议**：主结论＝最大带差：gap 0→0；gap 1→1；gap 2→2；gap ≥3→3（页面自己对 3 以上开始写「同时完成听力检查」「尽快评估」）。红旗＝覆盖（视产品决定：直接取 3，或至少 ≥2）。若需要各面向分数：L1 理解、L2 表达各自用 `gapOf` 同一规则，L3、L4 同。**不要用整体百分比**：它有 33% 的底，而且设计者自己说「真正该看的是每个面向的带差」。

### 8. 家长不能自己做／要观察
- 对家长友善；几乎全部是「平常看到」。有几题要家长刻意试：`你说「把球给我」…不可以用手指`、`桌上放两三样东西…`、`你说身体部位的名字…`、`问他叫什么名字`、`能向别人说明一个游戏的规则`、`比较难发的音 z c s zh ch sh`（家长判断）、`会看对象调整说话的方式`。
- 口腔 6 题与进食呛咳：家长可答，页面把「呛咳／作呕经常」当医疗端讯号。
- 没有计时、没有材料。

### 9. 旧版比较
无旧版（新增）。

### 10. 开放问题
1. **带差对单一题极敏感**：`domBand` 要求带内**所有题（含以下各带）全是「已经可以」**。一个 36 个月孩子在 B1 有一题「偶尔可以」→ lv=0 → 带差 4（「落后四个带，尽快评估」）。「不确定」也一样会卡住。这对家长手机作答的噪声承受度很差；引擎是否要自己重算（例如允许一题例外）？
2. **LQ 对「全部都答已经可以到某带才算」，而高于年龄带的题多半会答「还不行」**，这是设计的预期；带差只比较到年龄带，所以孩子在超前带有没通过不影响。
3. 年龄带宽度不等（B5–B7 各 12 个月）：在这些带里，孩子早一个带＝落后一年，晚一个带＝6 个月，带差的月数不可比。
4. 年龄范围外（<12 或 >72 月）没有带差，也就**没有等级**（grade 回「—」，score 回百分比），引擎要定义回退。
5. 「红旗覆盖」：8 项红旗里 `noword`、`noname`、`echo` 等是月龄条件，页面不自动判断，家长一勾就把整个结论换成「有需要特别注意的情形」。
6. 整体百分比有 33% 的结构下限（全部「还不行」＝33%）；`PCTB` 最差档 `<45` 仍可达（多数题「还不行」时）。
7. 口腔 6 题是否另一个维度（「吞咽／口腔」）供引擎使用？页面明确说独立。没有输出等级栏位（只有 `hits`/`often`/`some`/`na`）。
8. 没有早产矫正栏位。
9. 是否 `S.age.mo` 与 `f_age` 手动调整：LQ 的 `f_age` 是「可手动调整」文字（`"X 岁 Y 个月"`），但 `start()`／`ageBand` 只读出生与填写日期，**手动改不了任何计算**（与 GM 系列不同）。
