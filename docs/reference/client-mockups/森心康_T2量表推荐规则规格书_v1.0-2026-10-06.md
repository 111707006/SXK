**T2 量表推荐规则规格书**

依 T1 九大维度结果 × 诊断 × 年龄，为每位个案推荐 3–5 份第二层问卷

**版本　**v1.0（2026-09-24）

**交付对象　**IT 开发团队（附参考实现与规则配置）

**适用　**儿童 1–16 岁；量表库 31 份（24 份 T2 问卷＋7 份 T3 当面工具）

**需求方　**森心康 临床部

**0　一页看懂**

本规格书定义「第二层（T2）量表推荐引擎」：孩子做完 T1 九大能力筛查（36
题）后，系统依 **T1 结果、诊断、年龄、填写人条件**
四项输入，自动为每位个案挑出 **3–5 份**
第二层专项问卷，排好先后顺序，并为每一份写出推荐理由。IT
依本文件即可实现，不需要临床人员逐案判断。

**引擎流程（6 步）**

1.  整理输入：计算年龄段、可用填写人，从逐题作答中找出关键题标签（如「社交沟通警讯」「无口语」「安全题」）。

2.  安全闸门：出现安全题、动作红旗、语言落后未做听力检查时，先输出提示，这些不是量表但必须排在报告最前面。

3.  给九个维度排队：依红旗、诊断核心、T1
    严重度排出「需要评估的维度」清单（第 6 章）。

4.  规则必选：特定情况一定要加的量表先放入（如 16–30 个月有社交警讯 →
    M-CHAT-R/F）。

5.  逐维度挑量表：按维度的先后，从该维度的「首选顺序表」取第一份年龄合适、填写人可行、没超过同类上限的量表；重点维度再取第二份；再加生活质量基线；不足
    3 份时补足。

6.  检查时间上限、排序输出，并附上 T3 当面评估预告。

> 本引擎做的是「该先查什么」的排序，不是诊断。所有推荐都附理由文字，治疗师可在后台一键增删，系统需记录人工修改（第
> 13 章）。

**2　设计原则**

1.  **安全先于一切**：自伤、持续低落等安全题，以及动作红旗，先转介、先告知，再谈量表。

2.  **红旗先查**：红旗题代表「这个年龄不该出现的状况」，优先级高于一切分数。

3.  **诊断核心必查**：已有诊断（或疑似）时，该诊断的核心维度即使 T1
    看起来正常也要查，作为基线与确认。

4.  **先重后轻**：T1 明显 \> 中度 \>
    轻度；同级时依年龄阶段的发展重点排序（第 5 章）。

5.  **一维一主量表，重点维度才加深**：每个需要评估的维度先配一份主量表；只有红旗、诊断核心或明显落后的维度才配第二份。

6.  **年龄与填写人要可行**：量表年龄不符一律不推荐；没有上学就不推荐必须由教师填写的版本；11
    岁起加入本人自评。

7.  **不重复、不过量**：同类量表有上限（例如感觉处理只取一份），家长端合计不超过
    90 分钟。

8.  **可解释**：每份量表都要输出「为什么是它」；缺口（该年龄没有合适问卷）要明说，并改为当面评估。

9.  **不过度推销**：T1 全部正常又没有诊断时，不推荐 T2。

**6　优先级：哪些功能先评**

引擎先给每个维度一个「层级」，数字越小越先处理。每个维度只取最高（数字最小）的层级。

| **层级** | **条件** | **意义** | **处理方式** |
|----|----|----|----|
| P0 | 安全题未通过（E 组「持续两周以上低落」）；动作红旗（A 组未独走、B 组步态异常） | 可能有即时风险或需要医疗排查 | 不是量表：在报告与推荐清单最上方显示转介提示；安全题同时触发 SXK-EMO 由专业人员陪同填写 |
| P1 | 该维度有红旗题答「还不能」；或出现社交沟通警讯且社交维度 ≥ 轻度 | 这个年龄不该出现的状况 | 必须配主量表，并加第二份（深度） |
| P2 | 属于诊断档案的核心维度（不论 T1 等级） | 诊断的定义性功能，需要基线 | 必须配主量表，并加第二份（深度） |
| P3 | T1 中度（2）或明显（3） | 已明显影响生活 | 配主量表；明显落后再加第二份 |
| P4 | T1 轻度（1） | 需要确认是否真的落后 | 配主量表（名额够时） |
| P5 | 诊断档案的相关或鉴别维度，且 T1 ≥ 轻度 | 共病或其他解释 | 名额够时配主量表 |

**9.2　步骤**

1.  **准备**：由 ageM 求 band；可用填写人＝家长＋（上学且 ≥36
    月则教师）＋（≥132
    月则本人）。量表的填写人中只要有一个可用（治疗师除外），即视为可行。

2.  **标签**：依第 8 章扫描逐题作答，加上标签；加入 extraTags。

3.  **诊断过滤**：低于适用月龄的诊断档案移除（LDADHD、EMO 需 ≥36
    个月）；全部移除时视为 NONE。

4.  **P0 提示**：SAFETY → 安全转介；MED_MOT → 医疗转介；无口语标签或
    LANG ≥ 中度 → 听力检查前置提示（hearingChecked 为是时可省略）。

5.  **维度排队**：依第 6
    章给九个维度定层级，排除「不需要评估」者；排序键＝（层级，−T1
    等级，年龄段发展重点顺序）。若 T1 全部未见明显且 dx＝NONE →
    输出「不推荐 T2」并结束。

6.  **全面落后判定**：中度以上维度 ≥5 个 →
    全面落后模式：跨领域组上限放宽为 2，并先放入 SXK-ASQ3（≤66 月）或
    SXK-ADP（≤84 月）。

7.  **规则必选**（依序，年龄与上限合格才加）：R1 社交警讯 →
    M-CHAT-R/F；R3 安全 → SXK-EMO；R4 抽动 → SXK-TIC；R5 全面落后 →
    跨领域量表；再放入各诊断的必选量表。

8.  **覆盖**：依维度排队顺序，已被已选量表「主维度」覆盖的维度跳过；否则依
    9.1
    取第一份可用量表，记录理由「P层级＋维度＋原因」。若只能用次要量表 →
    记录缺口提示；若完全没有 → 记录「改为当面评估」。选满 5 份即停。

9.  **深度**：目标份数＝min(5, max(3, P1–P4
    维度数＋P1/P2/明显落后维度数))。未达目标时，对 P1、P2
    或明显落后且只有一份主量表的维度，依 9.1 再取下一份。

10. **生活质量基线**：有中度以上或有诊断，且未满 5 份 → 加 SXK-QOL。

11. **补足**：不足 max(3, min(目标,4)) 份时，依序补 SXK-QOL → SXK-ASQ3 →
    SXK-ADP → SXK-ADL。

12. **时间上限**：家长（含本人）端分钟数合计 \> 90 且多于 3
    份时，从优先级最低的开始移除（补足 → 基线 → P5 → P4 → 深度 → P3 →
    P2；同级先移除时间较长者）；规则必选、诊断必选、P1 永不移除。

13. **T3 预告**：构音标签 → SXK-ART；LANG ≥中度且 36–84 月 →
    SXK-PLE；LANG ≥中度且 85–155 月或叙事标签 → SXK-NAR；MOT
    ≥中度或书写标签 → SXK-SMA；学习警讯、72 月以上 LEARN
    ≥中度、或全面落后 → SXK-WISC；72 月以上 COG ≥中度 →
    SXK-ROCF（皆需年龄合适）。

14. **输出排序**：规则／诊断必选／P1 → P2 → P3 → 深度 → P4 → P5 → 基线 →
    补足；同级维持加入顺序。前两份标为「第一次填写」，其余为「第二次填写」（每次
    ≤45 分钟为宜）。

function recommend(input):

band ← bandOf(ageM); raters ← {P} ∪ ({T} if school ∧ ageM≥36) ∪ ({S} if
ageM≥132)

tags ← scanKeyItems(band, items) ∪ extraTags

if band = A ∧ ATT ∈ rfdims: rfdims += SOC

if SOC ∈ rfdims: tags += ASD_SIG

dx ← \[d for d in dx if ageM ≥ DX_MIN_AGE\[d\]\] or \[NONE\]

notes ← safetyNotes(tags, levels) \# P0

need ← sort(\[d for d in DIMS if tier(d) \< 9\], key = (tier(d),
−levels\[d\], AGE_ORDER\[band\]\[d\]))

if need = ∅ ∧ dx = \[NONE\]: return NO_T2

glob ← count(levels ≥ 2) ≥ GLOBAL_DELAY_DIMS

chosen ← \[\]

addIf(M-CHAT-R/F, ASD_SIG); addIf(SXK-EMO, SAFETY); addIf(SXK-TIC, TIC)

if glob: addFirst(\[SXK-ASQ3, SXK-ADP\])

for p in dxProfiles: for c in p.must: add(c) if \|chosen\| \< 5

for d in need: \# 覆盖

if \|chosen\| = 5: break

if d ∈ primaryCovered(chosen): continue

c ← firstUsable(pref(d)); if c: add(c, reason(d)) else notes += gap(d)

target ← min(5, max(3, count(tier ≤ 4) + count(tier ≤ 2 ∨ level = 3)))

for d in need where (tier(d) ≤ 2 ∨ levels\[d\] = 3) ∧ \|chosen\| \<
target: \# 深度

if countPrimary(chosen, d) \< 2: add(firstUsable(pref(d)))

if (any level ≥ 2 ∨ dx ≠ NONE) ∧ \|chosen\| \< 5: add(SXK-QOL)

fill from \[SXK-QOL, SXK-ASQ3, SXK-ADP, SXK-ADL\] until \|chosen\| ≥
max(3, min(target, 4))

while parentMinutes(chosen) \> 90 ∧ \|chosen\| \> 3: remove
lowest-priority droppable

t3 ← t3Preview(tags, levels, ageM)

return sortByPriority(chosen), t3, notes

usable(c) := c ∉ chosen ∧ c ∉ done ∧ minM(c) ≤ ageM ≤ maxM(c)

∧ (raters(c) \\ {C}) ∩ raters ≠ ∅ ∧ groupCount(c) \< groupMax(c)
