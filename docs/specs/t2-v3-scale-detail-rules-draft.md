# T2 v3 量表详解：判斷規則表（草稿，2026-10-15）

狀態：**草稿 v2（10-15 依家長角度定了 R1–R6 與大部分待確認）**；剩下的醫療判斷請客戶治療師看，看過、必要時請客戶治療師確認之後才寫程式。先做三份：粗大动作（SXK-GM）、注意力（SXK-AB／SXK-ATT）、感觉处理（SXK-SP）。
上游：`t2-v3-scale-detail-report.md`（量表详解 D-1…D-7，已實作、開關 `T2_SCALE_DETAIL` 預設關）。

## 0. 這份表要解決什麼

使用者 10-15：報告上要放**整理出來的結論**；家長的作答**可以引用，但要適度** —— 全部照搬顯得不專業、看不出重點。
所以每一段量表详解改成：

1. **結論**（一兩句，講「這代表什麼」）
2. **佐證**（最多 3 題原文＋家長選的那一格，例：「坐着时手脚一直动、扭来扭去（家长选：经常）」）
3. **建議**（照客戶 tips；有轉介條件就講轉介）

每條規則：**條件 → 結論句 → 佐證怎麼挑 → 建議 → 出處（客戶原句）→ 要不要治療師確認**。
出處欄引用的是題庫 `texts`（客戶治療師寫的 what／tips／levels），檔案在 `src/t2/kitv3/<code>.ts`。
「出處：無」＝客戶沒寫、是我推的，一律標 **需確認**。

### 0.1 家長想看到什麼（決定的依據）

使用者 10-15：「自己想一下使用者會希望看到的」。依據：10-15 確認過的範例截圖（粗大動作、社交與行為）、客戶《用语对照表》（9-11）、
客戶《量表推荐规则规格书》（10-06，最新）、原版量表的回饋形式（`docs/reference/原版量表回饋形式-2026-10-15.md`）。

家長打開這一段，依序想知道：

1. **要不要擔心、要不要去看專業** —— 一句話講完，放最前面。客戶 10-06：「安全先于一切……先转介、先告知，再谈量表」。
2. **孩子哪裡已經穩了** —— 先講。ASQ-3 官方培訓：先肯定已會的、再講正在練的；客戶：「结果正常时也要说清楚……可作为日后对照的基线」。
3. **哪裡要練、是什麼樣子** —— 結論＋兩三個具體例子。例子讓家長覺得「這份報告看得懂我的孩子」；整串清單反而看不出重點（使用者 10-15）。
4. **在家從哪一個開始、怎麼做** —— 範例已有的「下一步先练」與「在家可以这样练」。
5. **之後怎麼看進步** —— 三個月後對照。

寫法照客戶的「一句话结论公式」：**（能力方面）＋（中性描述）＋（行动建议）**，不用「孩子有……」當判定句；「保留信息量，只换掉情绪冲击」。

**決定（使用者授權我判斷，10-15）**

| # | 決定 | 理由 |
|---|---|---|
| R1 | 報告本文：**結論＋最多 3 題例子**；完整作答**不刪**，放進報告頁底下已經有的可摺疊「作答回顾」 | 家長要的是重點；想逐題看的家長與治療師還找得到（客戶原則「保留信息量」）。原版量表的家長版都不列題，逐題只在專業版 |
| R2 | 每個展開的面向**先講已經會的**（一句帶過，例：「单脚站以外，骑车、踢球、举高扔球都已经会了」），再講還在練的 | ASQ-3 官方做法；範例裡「已经会」那一欄改成這一句 |
| R3 | 「有沒有影響生活」**不改分級、只改語氣與急迫度**：有明顯影響時多給一個「不必等一个月，可以直接预约咨询」的選項；沒有影響時說「目前还没明显影响到生活」，建議照舊 | 分級照客戶切點（客戶的權威）；但家長說「已經嚴重影響家裡」時只回「先調環境」會讓家長覺得沒被聽到 |
| R4 | 感覺處理分**三個方向**（怕／躲、找刺激、没注意到），不用 Sensory Profile 2 的分類名 | 客戶 tips 只分這兩三種、建議相反；我們沒有常模，「比别人多很多」這類字會像在跟別人比 |
| R5 | 量表详解**不推銷新的問卷**（AT-8、SP-5 改成「咨询时可以提出」） | 客戶 10-06：「避免过度推销」；要做哪些問卷由推薦引擎決定，不由報告決定 |
| R6 | 報告最上方已經出的轉介提示（客戶 10-06 的 P0：动作红旗、安全题），量表详解**不再重講一遍**，只寫「见报告最上方的提示」 | 同一件事講兩次，家長會以為是兩個問題 |

### 0.2 引用作答的分寸（三份共用）

| 編號 | 規則 | 理由 |
|---|---|---|
| Q-1 | 一條結論最多引 **3 題**；整份量表详解最多引 **8 題**；完整作答在「作答回顾」（R1） | 使用者：照搬太多沒重點 |
| Q-2 | 關注類（AB／ATT／SP）挑「总是」先、再「经常」；同分挑面向裡排前面的 | 最重的最能說明結論 |
| Q-3 | 達成類（GM）挑「还不会」先、再「偶尔会」；同類挑**月齡最早**的那一題 | 「早該會的還不會」最有說明力（見 GM-8） |
| Q-4 | 全部穩定（GM 達成良好、關注類「未见明显」）**不引題** | 沒有要佐證的結論 |
| Q-5 | 「功能影响／有没有影响」那一段**不逐列照搬**；整理成一句（例：「家长认为主要影响在同伴关系与家庭关系（明显）」），只點名「明显／严重」或「有」的列 | 使用者：影響程度不能原樣上報告 |
| Q-6 | 佐證句一律帶家長選的那一格，不寫分數、不寫百分比 | 本表沒有常模，數字容易被讀成程度 |

## 2. 注意力（SXK-AB 3 岁起／SXK-ATT 4 岁起，關注類 `concern`）

計分：各面向＝得分／滿分；AB 切點 33／50、ATT 25／42。選項：很少或没有 0／偶尔 1／经常 2／总是 3。
ATT 每題另有標籤（IN 注意、HY 活动量、IM 冲动、EF 组织、ER 情绪）；AB 的面向就是這五類＋OD。
**題庫裡 ATT 沒有「持續多久／何時開始」**（交接說的 DUR／ONSET 只在 EMO），這一條不做。

## 3. 感觉处理（SXK-SP 幼儿家庭版 24–71 个月，關注類）
