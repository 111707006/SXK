# 線上干預要先買過 T2；線上干預自己的收費站疊在 T2 的後面

2026-09-29 定了「線上干預跟報告分開，從報告轉到線上干預那裡再收一次（現在先不收）」，實作時把線上干預的端點
（每週活動、整期計劃、示範片庫、單支活動、打卡、提醒與 .ics）從 T2 閘門搬出來，只走線上干預自己的收費站 —— **不看 T2 買了沒**。

使用者 2026-10-15 釐清（審查 #15）：兩次付費是分開的，但**有先後**。先付費做 T2、拿到 T2 報告；線上干預的購買入口只在 T2 報告裡，
沒買 T2 的家長根本碰不到線上干預。所以線上干預的端點要**兩道都過**：先看 T2 權益，再看線上干預的收費站（現在 0 元直接通過）。

## 為什麼

- 只走線上干預收費站時，沒買 T2 的人直接打 API 拿得到活動與打卡 —— 正常流程碰不到，等於後門。
- 線上干預頁本來就要讀最新報告（在 T2 閘門後面），沒買 T2 時畫面顯示「上鎖」是對的；端點跟畫面的規則一致。

## 怎麼做

`server.ts` 的 `/api/t2` 閘門：線上干預的路徑先 `denyIfT2Locked`，過了再 `denyIfTrainingLocked`；其餘路徑照舊只走 T2。
免費期間（`PAYWALL_FREE`）與展示開關兩道都放行，家長端現在看不出差別。之後要收線上干預的錢，照 `src/t2/trainingGate.ts` 檔頭
做線上干預的訂單與權益，接在 `denyIfTrainingLocked` 裡。
