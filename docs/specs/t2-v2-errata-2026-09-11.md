- **「完整」＝ `askedCount > 0 && answeredCount >= askedCount`**；「最新」看 `computedAt`，同一支同一時刻取輸入裡後面那筆；`computedAt` 解析不出來丟錯。舊紀錄帶 `age_out_of_window` 的**照算**（§5.6 說「僅供參考」，caveat 就是那句話的載體），不另外剔除。
- **`diagnosisDirection` 空字串 → `null`**（與 `planT2` 對中控台「未定」的讀法一致）；`sex` 沒給就沒有那個 key。
- **`aggregateDimensions` 對綠的維度、什麼都沒做 → `clear`、`tools` 空、`drivenBy` null**（票的固定輸入「其餘六維 clear 且 tools 空」）；黃的什麼都沒做 → `not_assessed`。

### K4. 不算矛盾，規格沒說（順手記）

- **退路只給一支、只在該維度這週一支都沒有時**：窗口內有一支、名額有兩個 → 第二個名額空著，不往下補。「窗口內沒有活動」讀成「窗口內沒有**拿得到**的活動」——窗口內那支被排在前面的維度拿走了（模組 7 的活動同時是 LANG 與 ATT 的候選），也算沒有。退路那一支已被別的維度拿走 → 取下一支最接近的。
- **退路下方同月齡有幾支** → 照打分挑（★ 對上的贏）、再編號小者；「最接近的一支」的「最接近」看 `targetMonth`，同月齡再看分。

- **`findings.child.assessedAgeMonth` 在配對裡只有一個用途**：問 `planT2` 客戶順序那一格是否非空（§8 第三鍵）。窗口一律用傳進來的實足月齡。
