## 2. 第 1 項：掃碼報告與後台報告

### 2.1 現況
- `/r/:token`（`server.ts:3786`）用 `renderParentExportHtml`（`src/admin/exportView.ts`）拼一頁純 HTML：九維表格＋AI 文字，**一張圖都沒有**。客戶說的「不完整」就是這個——與 App 裡的報告長得不一樣。
- 後台家長詳情（`ParentsPanel.tsx`）與列印（`ParentReportPrint.tsx`）已經嵌 `ReportBody`（ADR-0007），但**沒有 T2 報告**。
- 二維碼卡（`AnalysisReport.tsx` 約 151–182 行）顯示網址與「这个连结长期有效……」提醒句。

### 2.2 做法
1. **新的公開端點** `GET /api/r/:token`：照現在 `/r/:token` 的查法（token 形狀不對、查無、報告不在歷史裡一律 404，不退回最新一份；2 秒逾時），回 `{ child: {name, ageMonth, gender}, record }`——`record` 是那一筆報告快照（分數、AI 報告、`createdAt`），經 `reportHistory.ts` 收乾淨。**不帶手機號、帳號、其他報告**（歷次對照只畫到這一份為止的、存在快照裡的資料；拿不到就不畫那一塊）。
2. `/r/:token` 改回 SPA（同一個 `index.html`），前端看路徑進「掃碼報告頁」：打上面那支端點 → 畫 `ReportBody`，**所有插槽都不放**（沒有 T2 入口、二維碼卡、預約、語言專項入口）。404 時畫現在的「連結失效」字樣。
3. 刪 `renderParentExportHtml`、`reportLinkNotFoundHtml` 若沒人用一併刪；`src/admin/routes.ts:388` 的註解跟著改。
4. 二維碼卡：刪網址那一行與提醒句，只留二維碼、標題「把这份报告带回家」、說明「用手机相机扫一下……随时都能再看。」
5. 後台 T2 報告：`GET /api/admin/parents/:id` 多回這位家長最新的 T2 報告快照（舊版 `T2Findings` 或 `T2FindingsV3`，讀存的樣子，不重算、不叫模型）；`ParentsPanel` 詳情與 `ParentReportPrint` 在 T1 報告下面畫它。`T2Report`／`T2ReportV3` 要有**只讀模式**：沒有「生成」「重新生成」、預約、線上干預的按鈕。只在專案 A（B 沒有 T2）。
6. 二維碼只帶 T1 報告（現狀，不改）。

### 3.2 發育指數怎麼算
1. **逐題通過率表**（新資料檔，伺服器與測試共用；不進家長端 bundle）：180 題各一列，記「最小月齡時幾成做得到、最大月齡時幾成做得到」與**來源**：
   - `denver`：對得上丹佛 II 的題，用 Denver II-Jimma（*BMC Public Health* 2016，PMC4964036，Table 3，**CC BY 4.0**）的 25／50／75／90％ 月齡內插。檔頭註明出處與授權。
   - `cdc`：其次用 CDC 發展里程碑（75％ 的孩子做得到的月齡）。
   - `ai`：都查不到的（D、E 段大多）由 AI 判斷，標 `ai`。
2. 孩子篩查當時的月齡 → 每題「做得到」的機率 p；「有時」暫採 (1−p)/2、「還不能」其餘（Q-4）。
3. 36 題暫採**彼此獨立**，算出同月齡孩子總分的分布（卷積），取孩子總分的累積機率（同月齡孩子裡分數不高於他的比例），對到 CONTEXT.md 的五級（切點暫採，Q-5）：

   | 累積機率 | 級 | 發育指數 |
   |---|---|---|
   | >25％ | 正常範圍 | 100 |
   | 10–25％ | 約後 25％ | 90 |
   | 5–10％ | 約後 10％ | 80 |
   | 1–5％ | 約後 5％ | 75 |
   | ≤1％ | 更低 | 70 |
4. 已知限制（不寫在畫面上，寫在資料檔檔頭）：獨立假設會讓分布太窄、尾巴太薄，低分孩子容易被判得更低；丹佛常模來自衣索比亞樣本，不是中國孩子；`ai` 來源的題沒有依據。

### 3.2b 發育指數的另一種算法：達成率（D21，開關 `DEV_INDEX_BASIS=attainment`）
來源：客戶《森心康分龄发育综合评估_SXK-ASQ3_20260923.html》的 `buildReport`／`levelFor`：每領域 `Math.round(得分 ÷ 滿分 × 100)`，
參考帶 85／70／55（未见明显问题／轻微落后／中度落后／明显落后）。T1 照做，對象換成九維合計（滿分 72）：

| 達成率 | 客戶的分級 | 發育指數 |
|---|---|---|
| ≥85 | 未见明显问题 | 100 |
| 70–84 | 轻微落后 | 90 |
| 55–69 | 中度落后 | 80 |
| 40–54 | 明显落后 | 75（暫採 Q-9） |
| <40 | 明显落后 | 70（暫採 Q-9） |

- 只要九維總分，不要逐題作答：R1b 之前的舊成績也有數字（同齡估算是 null）。九維不齊、跨了兩個年齡段 → null。
- 程式：`src/developmentIndex/attainment.ts`；開關解析與選哪一支 `basis.ts`；`server.ts` 經 `createAdminRouter` 的 `developmentIndexOf` 傳給匯總與導出。
- 認不得的值程序起不來；不設或 `peer` 一行不動。

## 4. 第 3 項：字色與字級
