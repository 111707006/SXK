# 訓練計劃是第二條購買路；買 T2 只附一個月的居家訓練

客戶 2026-10-22 要「先付費後評估」：首頁「线上家庭个性化训练」點進去先買**訓練計劃**（一個月／三個月／六個月），買了篩查與深度評估都免費，評估完推每週活動。
使用者同日定：它與原本的「篩查免費 → 依被標記的維度買深度評估」**並存，不取代**。

兩條路並存就有一個漏洞：訓練計劃有期限，而 ADR-0012 之下買過 T2 的家長線上干預永久免費（收費站 0 元）——便宜的那條路拿得比較多，沒有人會買訓練計劃。
所以**買 T2 只附一個月的居家訓練**，之後要繼續就買訓練計劃（入口在 T2 報告與居家訓練頁）。ADR-0012 的「線上干預要先買過 T2」改成「要有一份還沒到期的居家訓練使用權」，來源是訓練計劃、兌換碼、代填或 T2 附送的一個月。

計劃長度對齊「一期 12 週」的推送：一個月＝這一期的前 4 週、三個月＝一期、六個月＝兩期。走訓練計劃的家長做完篩查就先依 T1 推定的顏色推，做了深度評估的方面下一期改用 T2 分級（推送規則本來就分這兩種來源）。

## Consequences

- ADR-0012 的兩道閘門（先 T2、再線上干預收費站）由「居家訓練使用權」一道取代；`TRAINING_PRICE_FEN` 只能 0 的限制跟著拿掉。
- 已經買過 T2、在這之前開始練的家長怎麼算（從開關打開那天起算一個月，或照舊不限期）寫進規格，屬於上線那一刻的過渡，不改這條規則。
