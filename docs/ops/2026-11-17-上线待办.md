# 你要做的事（2026-11-17）

程式我寫好了、開關都關著、還沒部署。下面是只有你能做的部分，照順序做。每一段最後寫「做完告訴我什麼」。

---

## 一、微信分账

### 0. 先決定一件事（最重要）

微信規定：**一筆訂單最多只能分出訂單金額的 30%**（商戶平台可設，預設上限就是 30%）。
你的清分設定是對方拿 80%。兩者對不上，例如一筆 ¥19.9：

| | 金額 |
|---|---|
| 清分算出對方該拿 | ¥15.82 |
| 微信最多讓分 | ¥5.97 |
| 剩下要線下給 | ¥9.85 |

三條路，選一條：

- **A. 照現在的程式走**：微信分到 30%，其餘後台標「线下结」，你每月照對帳表轉帳補齊。不用再做任何事。
- **B. 向微信申請提高上限**：商戶平台的「分账管理比例」頁面可以申請，通常要附合作協議，不保證批准、也未必批到 80%。批了之後把數字告訴我，我改一個設定即可。
- **C. 不用微信分账，全部線下結**：那就不要開這個功能，維持現狀（清分只算帳）。對方拿八成的情況下，這其實是最單純的做法。

> 我的建議：對方拿 80% 的話選 **C 或 A**。分账是為「平台拿大頭、分一小部分給別人」設計的，跟你的比例方向相反。
> 如果之後比例改成對方 ≤30%，分账才真的省事。

選 C 的話，這一大段後面都不用做。選 A 或 B 繼續：

### 1. 在商戶平台開通分账

1. 用**超級管理員**的微信掃碼登入 <https://pay.weixin.qq.com/>
2. 上方選單「产品中心」→「我的产品」→ 往下找「支付扩展工具」→「分账」→ 點「开通」
3. 照畫面同意協議；會要你輸入**操作密碼**和**簡訊驗證碼**
4. 開通後進「产品中心」→「分账」→「分账管理比例」，把最高比例設成 **30%**（選 B 的話在這裡申請更高）

官方說明（有截圖）：<https://pay.weixin.qq.com/doc/v3/merchant/4012067989>

**做完告訴我**：「分账開通了，比例設 XX%」。

### 2. 向每個合作方要收款資料

每個要收分账的對象（合作公司、推薦人）二選一：

**對方有微信支付商戶號（公司建議用這個）**，請對方提供：
- 商戶號（8–12 位數字）
- 商戶全稱：對方登入 <https://pay.weixin.qq.com/> →「账户中心」→「商户信息」裡的「商户全称」，**要一字不差**（括號全形半形都算）

**對方是個人（錢進他的微信零錢）**，請對方：
1. 用微信打開 <https://sxkscreen.com/>，用他的手機號登入
2. 進方案頁，按一次「立即开通」（**不必真的付款**，跳出付款畫面就可以關掉）
3. 把他登入用的手機號告訴你
4. 他的微信要做過實名認證（微信 →「我」→「服务」→ 右上角「…」→「实名认证」）

> 個人每月收款有微信的限額；金額大的對象請用商戶號。

**做完告訴我**：不用，資料你自己留著，第 4 步填。

### 3. 叫我部署

跟我說「部署分账」。我會做（你不用動手）：
1. 在正式站資料庫跑 `deploy/migrations/2026-11-17-profit-sharing.sql`（只加兩張新表）
2. 部署新版程式
3. 在 `.env` 加 `PROFIT_SHARING=1` 和 `PROFIT_SHARING_MAX_BP`（＝你在第 1 步設的比例）
4. 重啟並看日誌確認

### 4. 在後台登記接收方

1. 開 <https://sxkscreen.com/admin>，用全域管理員登入
2. 進「清分」分頁，拉到最下面「微信分账」→「分账接收方」
3. 每個對象一列：
   - 商戶：選「微信支付商户号」，填商戶號、商戶全稱，按「保存」
   - 個人：選「个人微信零钱」，在「用手机号查 openid」填他的手機號按「查」，自動帶入後按「保存」
4. 右邊狀態要變成「**可分账**」。如果寫「微信未添加成功」，下面會有微信給的原因（最常見是全稱不一致），改好再按一次保存

登記好之後，**之後的新訂單**才會帶分账標記；之前的訂單不會補分。

### 5. 第一筆真實分账（驗證）

分账沒有測試環境，第一次就是真錢，所以用最小金額驗：

1. 找一位歸屬該合作方的家長帳號（或用對方的進站連結新註冊一個），在微信裡買 1 個月方案（¥19.9）
2. 等 7 天（退款期）。想當天驗的話跟我說，我暫時把等待天數設成 0
3. 後台「清分」→「微信分账」→「分账单」會出現這一筆，狀態「到期待送」，並列出各方會分多少
4. 按「**执行分账**」→ 確認。這一步會真的轉錢
5. 過一兩分鐘再按一次，狀態應該變「已完成」
6. 到商戶平台「交易中心」→「分账」查這筆記錄，並請對方確認收到

**如果狀態是「失败」**：那一列會寫微信的原因。把那一行字貼給我。對照表：<https://pay.weixin.qq.com/doc/v3/merchant/4015505684>

### 開了分账之後要知道的事

- 帶分账標記的訂單，錢會**先凍結**在商戶號，分完才進可用餘額（最長 30 天）。所以一定要定期按「执行分账」，或叫我把自動執行打開。
- 分出去之後家長才退款：錢要你自己先墊，再跟對方要回來（程式沒有做自動追回）。所以才等 7 天再分。
- 「线下结」那一欄是你還欠對方的，要另外轉帳。

## 二、其他建議你做的（跟收錢有關）

### 6. 確認 H5 支付審核結果

登入 <https://pay.weixin.qq.com/> →「产品中心」→「我的产品」→「H5支付」，看是「已开通」還是被退回。
- 已開通：告訴我，我用手機瀏覽器實付一筆驗證流程（要你付款）
- 被退回：把退回原因貼給我

在通過之前，微信外的瀏覽器按付款會看到「请用微信打开本页再付款」（這次已改好，待部署）。

### 7. 拿掉正式站的測試碼

現在正式站有兩組所有人都能重複用的測試碼（VIP 兌換、半價券）。已經在收費，建議拿掉。
跟我說「拿掉測試碼」，我來做。

### 8. 出事通知（企業微信群機器人）

付款金額對不上、分账被拒、伺服器掛掉時，自動發到你的企業微信群：

1. 在企業微信建一個群（或用現有的內部群，**不能有外部聯絡人**）
2. 群右上角「…」→「添加群机器人」→「新创建一个机器人」→ 取名
3. 複製它給的 Webhook 網址（`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`）
4. 把網址給我，我設進 `.env`

官方說明：<https://developer.work.weixin.qq.com/document/path/91770>

### 9. 定 12 個月方案的價錢

方案頁的 12 個月那張卡現在寫「价格待定」。定了告訴我數字。
