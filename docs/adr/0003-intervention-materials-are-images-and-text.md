# 干預素材以圖文為主、影片連結為輔

需求說明書的 T2 干預包要求「分解步驟＋示範」。我們決定素材的主體是**一張圖配一句指令**的有序步驟，影片是**選填的外部連結**，存在 `intervention_materials.video_url` 這一個欄位裡。

## 為什麼不是影片為主

**這個 repo 完全沒有檔案上傳能力，`專案外部依賴清冊.md` 裡也沒有任何物件儲存服務。** 以影片為主體意味著要一次帶進三樣新東西：物件儲存（或點播服務）、上傳與轉檔的流程、以及一份新的帳單與備案責任。素材庫是 T2 的**前置**（issue #26 的配對邏輯等著它），把它擋在一個採購決定後面，等於整塊深度評估都不能動。

圖文另外解決兩件事：

- **家長的網路狀況不是我們能決定的。** 一張圖與一句話在弱網下仍然看得完，一段影片在同樣的條件下是一個轉不完的圈——而這一頁的用途是「現在陪孩子做一次」。
- **90 格的內容是要被人寫出來的。** 圖文改一個字就改完了；重錄一段影片不會發生，於是內容債會以「這一格的說法已經不對了但沒人動得了」的形式留著。

## 一併決定的事

- **網址只收 `https://` 或站內的 `/…` 路徑**（`src/utils/materialCells.ts`）。`http://` 的圖在 https 的頁面上會被瀏覽器當成混合內容擋掉——後台看起來存好了，家長那邊是一張破圖，而且沒有人會收到訊息。`javascript:` 與 `data:` 則是把一段可執行的東西存進資料庫再原樣貼到家長的頁面上。站內路徑要放行，是因為隨著建置一起出貨的 `public/` 圖檔是唯一不依賴外部主機的來源。
- **一格一筆，由資料庫的唯一鍵保證**（`uk_material_cell`）。少了它，同一格可以有兩筆素材，而配對邏輯取到哪一筆要看資料庫的心情——兩個同齡同狀況的孩子會拿到不同的訓練步驟，而且沒有任何一邊看起來是錯的。
- **只有停用，沒有刪除。** 停用後家長端取不到，內容還在，可以再打開。刪除會讓「這一格為什麼空著」永遠答不出來。
- **素材表沒有 `company_id`。** 它是森心康的干預內容，不是家長資料，因此不吃 ADR-0001 的公司條件；路由層改以「限定全域管理員」保護。豁免明列在 `test/adminScope.structure.test.ts` 的 `GLOBAL_TABLES`——想讓一張新表不帶公司條件，必須先去改那個檔案。

## 後果

- 圖片仍然託管在**別人的主機上**（外部 CDN 或圖床）。連結失效時家長看到的是破圖，而系統不會知道。這是這個決定的代價，目前接受：換成自有儲存是一個獨立的、隨時可以做的升級，而它不會改變資料模型——`imageUrl` 照樣是一個網址。
- 影片連結同樣不驗證可用性。後台存的是一個字串，不是一支能播的影片。
- ⚠️ `CONTEXT.md` 記載的**內容債仍然存在**：`sensory_processing` 的 T2/T3 內容實為精細動作、`emotion_behavior` 實為感覺處理。素材庫是照維度索引的，因此在那三個維度上，維護的人會照著錯的維度名稱去寫素材。產品端已知情並決定先照現狀做。這不是遺漏，是已選擇的取捨。
