# 線上干預推送看活動標籤，只推有示範片的

客戶 10/06《推送规则说明书》第四、五關是「維度 → 模組（`DIM_MOD`）→ 手冊適齡與月齡窗重疊 → 依編號」，
`targetMonth`、`targets` 不進配對（規格 P05、§7）。那時 300 支的 `targetMonth` 全是 NULL、片子只有 17 支，
正式站為了只推有片的開了 `TRAINING_SAMPLE_ONLY`：照編號排有片的活動，**不看維度也不看月齡**。

客戶 11/03 簡報第 26 頁：線上家庭訓練「換著玩」每個維度都是同樣五支片。使用者 2026-11-06：後台影片大部分已上傳（94 支），
要替影片貼標籤，讓推給家長的活動符合孩子 T2 的結果，推送規則跟著改。

## 決定

新開關 `TRAINING_PUSH_TAGS`（預設關，要配 `TRAINING_PUSH_V3`）。開著時新開的一期：

1. **只推有示範片的活動**（`videoUrl` 不是 null、啟用中）。`TRAINING_SAMPLE_ONLY` 對 v3 推送不再有作用。
2. **誰是這個維度的候選**：貼過標籤（`targets` 非空）的看標籤歸哪個維度（`lang.*` → 語言……），**不看模組**；
   標籤沒有這個維度的就不是它的候選。還沒貼標籤的照舊看 `DIM_MOD` 模組群。
3. **月齡**：貼過標籤的用 `targetMonth`（一個點）對窗口；還沒貼的照舊用手冊適齡 `ageMonths`。
   只有貼過標籤的才信 `targetMonth` —— 2026-10-06 替 300 支填的是虛構值。
4. **順序**：窗口內 → 貼過標籤的先、再避開上一期的（期末「稳定」）、再編號；窗口內不夠 → 放寬，依距離近→遠（同距離先往下），
   同距離貼過標籤的先。

不動的：顏色（T2 分級／T1 推定）、`PUSH_ORDER`、每月名額與交錯、月齡窗與三等分、12 週一期、本月做法、期末判檔、停用補位、換著玩的取法。
`avoidIf`、`dimensions` 仍不讀。報告的「這次看到：……」照舊不帶標籤句（`matchedTags: []`）：完整版快照沒有孩子的細標籤，
推送只知道維度。

一期開始時把規則記在那一期上（`plan.tagged: true`、`rulesVersion: push-tags-2026-11-07`）；**已經開了的一期照它存的規則走完 12 週**，
補位與換著玩也照那一期的規則。開關打開之後要馬上看到效果，就是重新生成 T2 報告（新快照從第 1 期重來）。

## 為什麼

- 標籤是後台給非技術人員下的（「示範片與標籤」分頁），貼上去要能看得到效果；不讀標籤，貼了等於沒貼。
- 一支片常常練到不只一個能力（A005 一二三木頭人：平衡＋「說停就停」）。模組只能放進一格，標籤可以放好幾個，
  推送照標籤走，注意力判紅時也推得到它。
- 只推有片的：沒片的活動畫面只有圖文，家長體驗落差大；客戶要的是「推片」。
- 沒標的退回模組＋手冊適齡：標籤會一批一批補，補完之前開關打開也排得出東西，不會整片「准备中」。

## 代價與還沒定的

- **片子少的維度會出現「准备中」**：94 支裡注意力 5、認知 4、日常生活 4、學習 6（`deploy/activity-tags/README.md`）。
  這幾個維度判紅時一期要 18 支，後面幾週排不滿。要嘛補片／補標籤，要嘛片用完時退回沒片的活動（圖文）——**暫採：不退**，待使用者定。
- 換著玩只列窗口內的；`targetMonth` 是一個點、月窗口兩三個月寬，標籤模式下換著玩多半是空的。11/03 第 25 頁已把按維度分的換著玩拿掉，暫不處理。
- 草稿的 `targetMonth` 是手冊適齡區間的中間，寬區間（2–8 岁 → 60）偏大，多半靠放寬才排進來；要治療師調。
- 舊規則（`TRAINING_PUSH_TAGS` 關、`TRAINING_SAMPLE_ONLY`）的程式碼留著，開關拿掉時另開票刪。
