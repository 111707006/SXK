# T2 完整版量表 → 孩子的细项（草稿，给治疗师看）

> 2026-11-19 · 使用者同日「全部同意」，已接进程式（ADR-0018，`src/t2/facetTagsV3.ts`，开关 `TRAINING_PUSH_CHILD_TAGS`）。
> 接的时候改了两处：CHEXI 计分本来就分两个因素，所以 F1 贴工作记忆、F2 贴抑制（不是整支两个都贴）；
> 气质三个表的两端顺序不同，照「要留意的那一端叫什么」贴。

## 这份表在做什么

家长做完 T2 完整版量表（客户 9/23 那一版，24 支）之后，系统现在只知道「哪个方面是红、黄、绿」，不知道孩子是「听不懂」还是「说不出」。
这份表替每支量表的每个面向（必要时逐题）指定**细项**。家长作答后，**某个面向被判为需要留意**，孩子就贴上那几个细项；
推送居家训练时，**同一个方面里，影片的细项跟孩子的细项对得上的先推**。

细项用的是后台「示范片与标签」那一页同一组字（57 个），所以孩子身上的细项能直接对到影片。

## 怎么来的

- 旧版量表（9/08，22 支）原本有一份对照（v2 规格 §5.9），换成完整版时没有接。
- 完整版很多面向**代号一样、内容换了**（例：社交 S3 旧的是模仿、新的是共同注意），旧表不能直接套。
  所以逐面向看**名称和题目**比对：内容相同的沿用旧判，内容换了的改判，旧版没有的面向看题目新判。
- 专案外的资料夹（SXK-wt 系列、下载、桌面）都找过，没有完整版量表的细项对照。

| 状态 | 意思 | 几列 |
|---|---|---|
| 沿用 | 面向名称和内容都跟旧版一样，照旧版贴 | 50 |
| 同内容换代号 | 内容等于旧版某个面向，只是代号或拆分方式变了 | 25 |
| 改判 | 代号跟旧版一样但内容换了，或旧判法不再合适 | 8 |
| 新判 | 旧版没有的面向或量表，我看题目判的 | 58 |
| 不贴 | 警讯、影响程度、生活质量这类，不是哪一种能力 | 10 |

「目前影片」是 11/16 那批影片标签里，贴了这个细项的影片有几支；「只进报告」的细项不配影片。

## 请治疗师特别看的地方

1. **建议新增两个细项**：「焦虑与担忧」（情绪量表 E1–E5）、「动作计划」（感觉量表 PL）。现有 57 个细项里没有对得上的；新增的话影片那边也要有人贴。
2. **⚠ 代号相同、内容换了的**：社交 S3／S4／S5、适应 A5、粗大动作 G4、执行功能 CHEXI（四个分量变成一个）。
3. **没有影片或影片很少的细项**（贴了也推不到片）：
   - 没有影片：语音觉识、听懂多于说出、口腔、安坐、阅读、如厕
   - 1–3 支：共同注意 3、发音 2、假装游戏 1、眼神接触 2、模仿 3、等待与轮流 1、听觉 3、触觉 3、持续完成 2、前庭 3、清洁 3、数学 1
4. **不贴的**：生活质量、抽动、功能影响、警讯题。请确认这些不需要配练习。
5. **ASR「活动量与参与度」**：偏高偏低都有可能，题目没分方向，暂不贴。
